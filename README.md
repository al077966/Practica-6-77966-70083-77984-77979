# Pratica-6
Al finalizar esta práctica, los estudiantes deberán:
• Comprender el proceso de modelado de un problema real en el contexto de la ingeniería
civil, desde el análisis hasta la validación de resultados.

• Aplicar estructuras de datos (listas y matrices) para representar información topográfica.

• Implementar funciones modulares en Python que realicen:

o Análisis: obtención y validación de datos.

o Diseño: creación de funciones que resuelvan el problema paso a paso.

o Pruebas: verificación de resultados con datos controlados.

• Calcular, a partir de matrices de elevaciones, los volúmenes totales de corte y de relleno
en un terreno.

• Integrar y ejecutar un programa que muestre los resultados de forma clara y verificable.
